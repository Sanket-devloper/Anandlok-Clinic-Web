# News / Press Images

Place WebP images for the Gallery > News section in this folder.

Guidelines:
- Use `.webp` format.
- Filenames can be arbitrary; images will be displayed in the order they are named and loaded.
- Example filenames: `press-1.webp`, `press-2.webp`, `press-3.webp`.

The Gallery page will list these under the "News" filter and they will open in the same fullscreen lightbox as other photos.
