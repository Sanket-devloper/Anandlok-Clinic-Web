# Gallery Images

Place WebP images for the Gallery page in this folder.

Naming guidance:
- Files should be `.webp` images.
- Filenames will be used to generate simple titles (e.g. `abhyanga-session.webp` → "Abhyanga Session").
- Example files you can add:
  - `abhyanga-session.webp`
  - `treatment-room-1.webp`
  - `panchakarma-therapy.webp`

The Gallery page will automatically list all `.webp` files in this folder under the "Photos" filter.

Display note:
- Images are shown with numeric labels in the gallery ("Image 1", "Image 2", ...), regardless of filename. Filenames are only used to load files.
