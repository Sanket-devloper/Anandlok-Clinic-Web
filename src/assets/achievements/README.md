# Achievements Images

Place WebP images for the Awards and Achievements section in this folder.

Use `.webp` files only. The achievements cards on the Home page and About page will load images from this folder automatically when they exist.

Recommended naming by year:
- `award-2014.webp`
- `award-2015.webp`
- `award-2016.webp`
- `award-2017.webp`
- `award-2018.webp`
- `award-2019.webp`
- `award-2021.webp`
- `award-2022.webp`
- `award-2023.webp`
- `award-2024.webp`
- `award-2025.webp`
- `award-2026.webp`

If you have more than one award from the same year, you can reuse the same year-based image for both cards or adjust the filename pattern later if you want one image per award entry.

If you add more images, keep using the same `award-YYYY.webp` pattern so they stay easy to manage.
