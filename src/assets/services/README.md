# Services Images

Place WebP images for the Services page in this folder.

Naming convention:
- `consultation.webp`
- `consultation-standard.webp` (use this for the standard Authentic Ayurvedic Diagnosis & Consultation visual)
- `panchakarma.webp`
- `treatments.webp`
- `uturn.webp`
- `spinowalk.webp`
- `heart.webp`
- `hope.webp`
- `diet.webp`
- `marma.webp`
- `yoga.webp`
- `rejuvenation.webp`

The Services page will automatically use a matching image when the file exists, and fall back to the clinic placeholder until then.
